### Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Ensure dataset is hosted publicly (e.g., on GitHub) and update the URL in the code.

### Running Part 1
- `python code/part1.py`
- Implements gradient descent from scratch.

### Running Part 2
- `python code/part2.py`
- Uses Scikit-Learn's SGDRegressor.

### Files
- `code/part1.py`: Custom implementation
- `code/part2.py`: Library implementation
- `logs/`: Log files for trials
- `plots/`: Generated plots
- `report/report.md`: Report with logs, answers, and plots
- `requirements.txt`: Python dependencies
